## 📖 Overview

This directory defines **Phase 3** of the course progression. Phases act as high-level chronological and thematic wrappers that group multiple weekly modules together based on major pedagogical milestones (e.g., the OSEMN framework transitions). 

This phase specifically focuses on `chunking, embedding generation, VDB schema design, and few-shot trope/genre classification`.

> **⚠️ Phase Routing Notice**
> This directory acts primarily as an organizational wrapper. Ensure that granular lecture assets, code snippets, and weekly materials are placed within their respective `module_XX/` subdirectories, rather than loosely at the root of the phase directory.
