## 📖 Overview

This directory acts as the master index for the weekly, topic-based execution of the course. Each **Module** typically spans one to three lectures and encompasses a specific technical concept, homework assignment, or laboratory exercise. 

These modules roll up conceptually into the higher-level [Phases](../phases/) of the course taxonomy.

> **⚠️ Parent Directory Routing Notice**
> Core lecture markdown files and major assignments live in the top-level `lectures/` and `assignments/` directories to maintain structural parity. The `module_XX/` subdirectories herein are used exclusively to store localized data snippets, lab code examples, module-specific images, or environment configs required for that week's content.
